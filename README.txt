Dungeon Merchant

For installation, controls, beginner guidance and source documentation, open README.md.
Beginner guide: docs/QUICKSTART.md

Run the source with Python 3.10 or later: python main.py
Windows: double-click Start Game.bat.
Runtime dependencies: Python standard library and a modern browser.

Windows builds are available through GitHub Releases.
Source saves: saves/save.json
Packaged saves: %LOCALAPPDATA%\DungeonMerchant\save.json

The story ends after debt repayment and victory over the family nemesis.
See CREDITS.md for asset and audio distribution notes.
