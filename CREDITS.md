# Credits and distribution notes

- Game code: Python standard library, HTML, CSS and JavaScript, developed with AI assistance.
- Illustrations: OpenAI image generation; prompts are retained in asset metadata and prompt files.
- Public-release sound effects: original procedural synthesis. `tools/generate_public_audio.py` creates these effects without imported recordings. `coin-rattle.wav` was also synthesized from code.
- Imported ambient music, battle music and user-provided recordings are excluded from the public source package and Windows build while redistribution permissions are unconfirmed. No permission is claimed for those omitted recordings.
- Packaging tool: PyInstaller. The Python interpreter and build dependencies retain their own licences and notices.

This repository is shared for playing and reviewing the project. It has no general open-source licence; public access alone does not grant redistribution rights to game code or art.
